B.Tech AI & ML Specialization

First Year Goal: Master Core Programming & Computational Thinking

Focus on procedural thinking in C, object-oriented concepts in C++, and foundational Engineering Mathematics (Matrices & Calculus).

Semester 1 Core Coursework

C Programming & Engineering Math I

  • • Flowcharts, Conditionals, Loops, & Memory Layout
  • • Pointers, Dynamic Memory Allocation (malloc, free)
  • • Linear Algebra, Eigenvalues & Matrix Factorization
Semester 2 Core Coursework

C++ OOP & Digital Electronics

  • • Classes, Constructors, Encapsulation, & Polymorphism
  • • Templates, Standard Template Library (STL basics)
  • • Boolean Algebra, Logic Gates, & Combinational Circuits

Second Year Goal: Java, Data Structures & System Internals

Construct scalable software with Java Collections, learn Data Structures & Algorithms (DSA), and master Databases (DBMS) and Operating Systems.

Semester 3 Core Architecture

Java OOP & Data Structures

  • • Java Multithreading, Exception Handling & Collections Framework
  • • Linked Lists, Stacks, Queues, Binary Trees & Heaps
  • • Time Complexity ($O(N)$, $O(\log N)$) & Algorithm Optimization
Semester 4 System Core

DBMS, OS & Graph Algorithms

  • • SQL Queries, Indexing, Normalization (1NF to BCNF), ACID Properties
  • • Process Scheduling, Deadlocks, Virtual Memory & Paging
  • • Graph Traversals (BFS, DFS, Dijkstra’s Shortest Path)

Third Year Goal: Applied AI, Machine Learning & Deep Learning

Apply Python libraries (NumPy, Pandas, Scikit-Learn, PyTorch) to train regression models, Neural Networks, Computer Vision, and NLP pipelines.

Semester 5 Core Machine Learning

Supervised & Unsupervised ML

  • • Linear/Logistic Regression, Decision Trees, Random Forests
  • • K-Means Clustering, Principal Component Analysis (PCA)
  • • Model Evaluation: Cross-Validation, ROC-AUC, F1-Score
Semester 6 Deep Learning & Vision

Neural Networks, CNNs & NLP

  • • Multi-Layer Perceptrons, Backpropagation, Gradient Descent
  • • Convolutional Neural Networks (CNNs) for Image Classification
  • • Recurrent Networks (LSTMs, GRUs) & Transformer Attention

Fourth Year Goal: Production Deployment & Placement Mastery

Publish capstone engineering projects, containerize AI models with Docker, scale web APIs via FastAPI, and clear technical interview rounds.

Semester 7 MLOps & Cloud

MLOps, FastAPI & Cloud Deployments

  • • Model Serialization (ONNX, Pickle) and RESTful API endpoints
  • • Docker Containerization & CI/CD deployment pipelines
  • • Real-Time Inference Optimization & Cloud GPUs (AWS/GCP)
Semester 8 Graduation & Placement

Major Capstone & Coding Interviews

  • • Multi-modal Generative AI Capstone Project
  • • LeetCode / Hard DSA Problem Solving (Dynamic Programming)
  • • System Design Architecture & Mock Interview Assessments
